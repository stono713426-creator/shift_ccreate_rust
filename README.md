# 勤務シフト自動生成システム (Rust Edition)

> Version: v2.0.0  
> Release Date: 2026-11-21  
> Status: v2.0.0 Major Upgrade (厳格最適化＆原因診断・対話緩和選択モデル)

医療機関等の複雑な勤務シフト制約を、オープンソース最高峰の数理最適化ソルバー（MILP: HiGHS）によって解決し、現場フォーマットの Excel 帳票として出力する **純Rust製ネイティブ・デスクトップアプリケーション** です。

`v2.0.0` では、従来の「解なしを避けるための無断スラック緩和・事前クランプ」を全面廃止し、**実務上守るべき条件を厳格に維持したうえで、両立不能時は「適切解なし」と明示して原因診断および選択式緩和候補を提示する対話型エンジン**へ刷新しました。

---

## v2.0.0 の主な特徴と技術構成

1. **3層制約設計・厳格最適化 ＆ 原因診断エンジン (`solver.rs` / MILP HiGHS)**:
   - **`good_lp` + `highs`（C++ ネイティブエンジン同梱）** を採用し、全制約を 100% 厳密な線形不等式として求解。
   - **Tier 0（絶対不変・緩和不可・緩和候補提示なし）**:
     - 除外スタッフ、日曜・祝日・全員共通特別有休（年末年始/夏季休診）、確定休暇（有休・特別有休・希望休・指定公休）、**月跨ぎを含む連勤上限**（前月末尾実績の無断書き換えを廃止）、非コア固定出勤曜日、無効な適用条件書式。
   - **Tier 1（厳格ハード制約・両立不能時は停止＆診断提示）**:
     - コアスタッフ月間所定勤務日数（希望休超過時の無断クランプ廃止・固定公休削減許容による所定割れ廃止）、固定公休5回月の共通公休数優先振替（所定一致＆連勤上限遵守）、2階裏外来最低総数・職種別（看護師/検査）最低人数、Ope専従スタッフの Ope/注射日必須出勤、週4祝日非連動・条件付水曜公休、特別枠（`必要に応じて週5`）の通常時週4基準厳守、シフト制約条件シートの `HARD` 系ルール。
   - **Tier 2（品質最適化ソフト制約）**:
     - 2階裏4名枠の優先順是正：**① Ope日推奨体制 (`Ns>=2 & 検>=2`, 5.5M) ＞ ② 非Ope早上がり重複時フルタイム+1 (3.5M) ＞ ③ 通常週4名最低日数 (2.5M)**。
     - `祝日週_公休設定` を所定日数を割り込まない範囲のソフト優先配分（600k）へ調整（固定公休スタッフの所定不足を解消）。
     - 暦3連休抑制（日祝含む連続3暦日、有休/特有/全休除外）、7暦日ローリング平準化（日祝・休診・有休/特有を除外した稼働可能日ベース）、過去3ヶ月ローテーション履歴の重み適正化。
   - **原因診断用 MILP (`diagnose_infeasibility`)**:
     - 厳格探索で適切解が得られない場合、構造的ボトルネック（日次/週次人員不足、月跨ぎ連勤競合、個人所定日数超過、HARD制約不足）と診断用MILPによる **最小限の推奨ピンポイント緩和候補・代替/一括候補・最終手段（所定日数±1日調整）** を自動抽出。

2. **属性ベースルール ＆ 堅牢な勤務条件パーサー (`parser.rs` / `holidays.rs`)**:
   - **スタッフマスタ「個別勤務ルール」列（v2.0.0追加）**: `早上がり` / `Ope専従` / `週4祝日非連動` / `非Ope水曜公休` を属性として指定可能（未記入時は旧フォーマット互換で自動判定）。
   - NFKC 正規化（全角「週４日」等対応）、Excel シリアル値・単体日付セル（年省略時の対象月年補完）、和暦（令和/`R`）、存在しない日付警告、厳格化された PM 有休抽出（`PM`/`午後`/`午後半休` のみ判定し単なる `半休`/`午前半休` の誤発火を防止）。
   - 複数曜日表記（`火曜・水曜`）、未知の適用条件書式エラー検出、除外スタッフによる人数補正バグ・`同時休み不可` 解釈バグ修正、旧 Excel の重複 Ope ルール自動整理。
   - 対象年月に応じた **動的祝日カレンダー範囲**（2031年以降も自動計算・Web API マージ対応）。

3. **現場フォーマット Excel 出力 ＆ 生成診断レポート (`renderer.rs`)**:
   - A4 横向き印刷（1×1 ページ適合）、ウィンドウ枠固定（`E3`）、水平中央寄せ。
   - Ope日における「2階裏 人数」列数式からの `is_ope_dedicated` スタッフ自動減算（`=COUNTIF(...)-COUNTIF(...)`）、およびクリニック全体休診日（年末年始・夏季休診）での `⚠️` 警告誤表示の除外。
   - 適切解なし・未生成月の診断シート（`{year}年{month:02}月_未生成`）出力と、**ブック末尾への `生成診断レポート` シート自動追加**（月別サマリー、適用済み緩和条件、未生成月の原因・緩和候補、品質詳細ログ）。

4. **対話的緩和選択デスクトップ GUI (`gui.rs`) ＆ 厳格 CLI (`main.rs`)**:
   - **GUI**: 複数月生成中に「適切解なし」の月で自動一時停止し、検出された原因とグループ別チェックリスト（① 推奨ピンポイント / ② 代替・一括 / ⚠️ ③ 最終手段）を表示。「✨ 推奨候補を一括選択」「🔄 選択した緩和条件で再試行」「⏭ スキップ」「🛑 中止」により対話しながら翌月へ引き継いで生成可能。
   - **CLI**: 無承認の自動緩和は一切行わず、未解決月は「適切解なし (未生成)」として明示停止し、原因と推奨緩和候補をコンソールおよび Excel レポートに出力。

## 使い方

### 1. デスクトップ GUI で使う場合 (推奨)
`shift_create_rust.exe` を引数なしでダブルクリックして起動します（Windows GUI サブシステムによりコンソールウィンドウは開きません）。  
同梱の標準テンプレート **`勤務条件表_ひな形.xlsx`**（v2.0.0：個別勤務ルール列・整理済み9件の制約条件・参照区分カラー・入力規則・記入ガイド付き）を基に入力してください。

```text
1. 「📁 選択...」または「🔍 自動検出」をクリックして勤務条件表 Excel を読み込みます。
2. スタッフ数・制約条件・手術日程・対象月チェックボックスおよび入力警告の有無を確認します。
3. 「🚀 シフト自動生成を開始（厳格探索）」をクリックします。
4. 厳格条件で解ける月は自動進行し、「適切解なし」の月があれば原因と緩和候補が表示されます。
   必要に応じて推奨/代替緩和をチェックし「🔄 選択した緩和条件で再試行」（またはスキップ）で続行します。
5. 完了後、「📊 出力 Excel を開く」からシフト表と末尾の「生成診断レポート」を確認できます。
```

### 2. コマンドライン (CLI) で使う場合
```powershell
# 基本実行 (標準ひな形からデフォルト命名規則で出力、無承認緩和なし)
shift_create_rust.exe 勤務条件表_ひな形.xlsx

# 出力先パスを指定して実行
shift_create_rust.exe 勤務条件表_ひな形.xlsx 2026年秋シフト.xlsx

# ヘルプ表示
shift_create_rust.exe --help
```

## ビルドとテスト

開発・回帰テストの標準条件表としてプロジェクト直下の **`勤務条件表_ひな形.xlsx`** を使用します。

```powershell
# 標準ひな形 Excel (勤務条件表_ひな形.xlsx) の再生成
cargo run --example generate_template

# 全 35 件のテスト実行 (lib単体 17 件 + 統合回帰 18 件)
cargo test

# 配布用リリースビルド (ファイルバージョン v2.0.0 埋め込み)
cargo build --release
```
