# 勤務シフト自動生成システム (Rust Edition)

> Version: v1.2.1  
> Release Date: 2026-11-05  
> Status: v1.2.1 Released & Verified 🎉

医療機関等の複雑な勤務シフト制約を、オープンソース最高峰の数理最適化ソルバー（MILP: HiGHS）によって高速解決し、現場フォーマットの Excel 帳票として出力する **純Rust製ネイティブ・デスクトップアプリケーション** です（Python版 `sift_create` v1.9.1 の全仕様完全移植プロジェクト）。

---

## 主な特徴と技術構成

1. **二段階・数理最適化エンジン (MILP / HiGHS)**:
   - `good_lp` + `highs`（C++ ネイティブエンジン同梱）を採用。
   - **Stage 1 (厳格探索)**: 全制約を完全遵守する最適解を探索。
   - **Stage 2 (スラック緩和探索)**: 優先度（HARD / HIGH / SOFT / LOW の 10 段階重み）に基づき、数理的に解が存在しない場合も最適な妥協案を自動導出。
   - 実データ（25名 × 7ヶ月分）の最適化を **わずか数秒** で解く圧倒的なパフォーマンス。

2. **堅牢な日付パース ＆ 祝日カレンダー**:
   - NFKC 正規化、Excel シリアル値、時刻付き範囲、全角半角混在の完全自動認識。
   - 内閣府祝日計算ロジック（春分・秋分・国民の休日・振替休日）＋ 内閣府公式 Web API のマージ取得。

3. **現場フォーマット Excel 完全準拠レンダラー (`rust_xlsxwriter`)**:
   - A4 横向き印刷（1×1 ページ適合）、ウィンドウ枠固定（`E3`）、水平中央寄せ。
   - セクション別（2階表・2階裏・1階・総出勤人数）のカラーヘッダーとスタッフ列配置。
   - 日曜・祝日行の「休業」表示、手術日「○」（深緑）、公休「公」（グレー）、有休・特有表示。
   - 2階裏体制警告（`⚠️`）列の自動判定。
   - Excel 式 `=COUNTIF(...)` によるリアルタイム合計出勤日数・公休日数集計、所定勤務日数、主公休曜日表示。

4. **複数月連続生成 ＆ 月跨ぎ実績引き継ぎ**:
   - 前月の主公休曜日履歴を引き継ぎ、過去3ヶ月の曜日ローテーションペナルティを遵守。
   - 前月末尾7日間の出勤フラグを引き継ぎ、月初5連勤上限を厳格管理。

5. **モダン・デスクトップ GUI (`eframe` / `egui`) ＆ CLI ハイブリッド対応**:
   - Windows 標準日本語フォント（メイリオ / 游ゴシック）の自動ロードにより、文字化けゼロ。
   - 条件表 Excel の自動検出 ＆ ファイルピッカー（`rfd`）。
   - 軽量プレビュー（スタッフ数、制約数、手術日程、対象月チェックボックス）。
   - ワーカースレッドによる非同期ソルブ、リアルタイムプログレスバー、スクロールログ表示。
   - 生成完了後の「出力 Excel を開く」「保存先フォルダを開く」ワンクリック起動。

## 使い方

### 1. デスクトップ GUI で使う場合 (推奨)
`shift_create_rust.exe` を引数なしでダブルクリックして起動します。  
配布パッケージには標準入力テンプレート **`勤務条件表_ひな形.xlsx`**（有効項目・補助項目・メモ項目の色分け、プルダウン入力規則、セルコメント、記入ガイドシート付き）が同梱されています。

```text
1. 「📁 選択...」または「🔍 自動検出」をクリックして勤務条件表 Excel（同梱の 勤務条件表_ひな形.xlsx またはそのコピー）を読み込みます。
2. スタッフ数や制約条件のプレビュー、作成対象月を確認します。
3. 「🚀 シフト自動生成を開始」をクリックします。
4. 数秒で全月のシフト表が完成します。「📊 出力 Excel を開く」で Excel を開いて確認・印刷できます。
```

### 2. コマンドライン (CLI) で使う場合
```powershell
# 基本実行 (標準ひな形からデフォルト命名規則で出力)
shift_create_rust.exe 勤務条件表_ひな形.xlsx

# 出力先パスを指定して実行
shift_create_rust.exe 勤務条件表_ひな形.xlsx 2026年秋シフト.xlsx

# ヘルプ表示
shift_create_rust.exe --help
```

## ビルドとテスト

開発・回帰テストの標準条件表としてプロジェクト直下の **`勤務条件表_ひな形.xlsx`** を使用します。

```powershell
# 標準ひな形 Excel (勤務条件表_ひな形.xlsx) の再生成
cargo run --example generate_template

# 全 22 件のテスト実行 (ユニット 10 件 + 統合回帰 12 件)
cargo test

# 配布用リリースビルド (ファイルバージョン v1.2.1 埋め込み)
cargo build --release
```

  - `README.txt` (配布用マニュアル)
